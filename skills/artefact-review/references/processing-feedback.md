# Processing feedback

Feedback can come in any format. Where it isn't already broken down into individual findings, you MUST break it down first.

Whoever raised a finding, you MUST judge it against the requirements, the conventions, and your priorities. You MUST NOT accept a finding to be agreeable.

You MUST respond to each finding in one of the following ways:

- Address it, if you agree with it. Where it prescribes a fix, you MAY address it differently.
- Dispute it, if you disagree with it, or with addressing it now (e.g., it would cost more than it delivers, it belongs in a separate change).
- Escalate it, if you agree with it, but addressing it would change the brief (e.g., it contradicts a requirement, it adds a new one), and you aren't sure that whoever raised it has the authority to change the brief.

Where a finding is ambiguous, you SHOULD act on a reasonable interpretation of it, and state that interpretation in your reply.
